# Firmware Artifacts

This folder contains the latest prebuilt custom firmware for the Seeed Studio SenseCAP T1000-E telemetry bot.

- `t1000e_companion_radio_ble-telemetry-bot.zip`: use with the MeshCore/Web nRF flasher.
- `t1000e_companion_radio_ble-telemetry-bot.uf2`: use only for UF2 drag-and-drop flashing in DFU mode.

See `docs/t1000e-telemetry-bot.md` for flashing and command documentation.
